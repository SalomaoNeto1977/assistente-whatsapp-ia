# Assistente WhatsApp IA

Aplicação Android local para responder automaticamente, por IA, às mensagens recebidas através das notificações do WhatsApp e WhatsApp Business.

## Versão 1.0

- Modos: desligado, sempre ativo, apenas com o ecrã bloqueado/standby.
- Delay aleatório configurável antes da resposta.
- Prefixo configurável (ex.: `🤖 Assistente:` ou `Salomão Neto:`).
- Campo de instruções/conhecimento para ensinar a IA.
- Ligação à OpenAI Responses API através de chave introduzida pelo utilizador.
- Resposta através da ação RemoteInput da notificação do WhatsApp.
- Sem necessidade de root.

> Esta primeira versão destina-se a uso pessoal/local. A chave da API é guardada no armazenamento privado da app; não distribuas uma APK configurada com a tua chave.
